# Contributing to VisualSync AI
We welcome contributions from the open-source community, especially around:

1. New Provider Adapters: Adding support for local vision models (LLaVA, Moondream2) and speech-to-text engines.

2. Pacing & Anchor Heuristics: Improving millisecond boundary math in sentenceAnchors.

3. Rate-Limit Resilience: Enhancing key-pool rotation and backoff strategies.

## How to Submit a Pull Request

1. Fork the repository and create your feature branch (git checkout -b feat/new-adapter).

2. Ensure all timeline validation schemas pass.

3. Open a Pull Request with a clear description of the architectural changes.
